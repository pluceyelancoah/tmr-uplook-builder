How to use

  1. 1In your TMR Tracker feed system, export the Load report for the full month as CSV. The older monthly ingredient report (CSV or Excel) still works too.
  2. 2Drop that file in the box below.
  3. 3Review the three steps so you can see the premixes broken down and the totals line up.
  4. 4Click Download file for UpLook, then open UpLook separately and upload that file there.
Show me how to export the older monthly ingredient report
  1. In the bottom-right corner, set the template chooser to the Elanco template — this makes sure the correct columns are exported.
  2. Click Export and save the file as CSV or Excel.

Runs entirely on your computer — your feed data never leaves this page. Amounts are dry matter; ingredients are named by their feed code (report descriptions aren't always reliable).
